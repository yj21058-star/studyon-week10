# 스터디온 · 10주차

9주차의 학습 계획 폼과 보관함을 이어서 수정했다. 긴 페이지에서 필요한 기능을 찾기 쉽도록 메뉴를 정리하고, 보관한 계획을 상태별로 골라 볼 수 있게 했다.

## 메뉴와 이동

| 메뉴 | 목적지 |
| --- | --- |
| 계획 만들기 | 과목·목표·시간·마감일 입력, 확인, 저장 |
| 내 계획 보관함 | 저장한 계획 목록과 상세, 완료 상태 관리 |
| 학습 도구 | 계획 가이드, 시간 계산, 준비 점검 |
| 서비스 안내 | 서비스 소개, 주요 기능, 이용 방법 |

메뉴는 `nav`, `ul`, `li`로 구성했다. 현재 메뉴에는 색과 ‘현재’ 문구를 표시하고 `aria-current`를 적용했다. 주소의 `#start`, `#saved-plans`, `#workspace`, `#about`에 맞춰 화면을 바꾸므로 새로고침이나 뒤로 가기 후에도 실제 위치와 표시가 일치한다. 메뉴를 오갈 때 작성 중인 입력은 유지된다.

## 필터와 모바일 메뉴

보관함에 전체·학습 예정·학습 완료 버튼을 넣었다. 선택한 버튼의 표시와 `aria-pressed`, 목록, 결과 수를 함께 갱신한다. 보관함 자체가 비어 있으면 계획 만들기를 안내하고, 선택한 상태에 결과만 없으면 전체 계획으로 돌아갈 수 있게 했다.

768px 이하에서는 메뉴 열기·닫기 버튼을 사용한다. 펼침 상태에 따라 버튼 문구와 `aria-expanded`가 바뀌고, 목적지를 누르면 이동한 뒤 메뉴가 닫힌다. 넓은 화면에서는 메뉴를 항상 표시한다.

## 확인 순서와 결과

2026년 11월 6일 브라우저에서 확인했다.

1. 보관함 → 학습 도구 → 브라우저 뒤로 가기 순서로 이동했다. 보관함 화면과 현재 메뉴 표시가 일치했다. 새로고침 후에도 같은 위치가 표시됐고 저장한 계획과 완료 상태가 남았다.
2. 완료한 계획이 없는 상태에서 학습 완료 필터를 눌렀다. 0개 안내와 전체 계획 보기 버튼이 나타났다. 이후 계획을 완료로 바꾸니 완료 필터에 1개가 표시됐다.
3. 좁은 화면에서 메뉴를 열고 계획 만들기를 선택했다. 목적지로 이동하면서 메뉴가 닫혔다. 입력 → 확인 → 수정 → 저장 → 상세 → 목록 → 학습 예정 필터까지 동작했다.
4. 삭제 확인에서 계획 유지를 눌렀다. 내용과 상태가 그대로 남았다.

PC 너비 1348px와 브라우저 확대를 이용한 좁은 너비 337px에서 확인했다. 좁은 화면에서 가로 넘침이 없었고 입력창과 버튼도 화면 안에 들어왔다. 실제 휴대폰 기기 테스트는 별도로 하지 않았다.
